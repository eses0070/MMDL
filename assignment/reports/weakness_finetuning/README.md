## 1. 목적과 현재 판단

MMMU의 취약 과목에 공통으로 필요한 표·그래프 해석, 수치 계산, 과학 도식 이해, 공간 대응 등을 정답 데이터 기반 미세조정으로 보완하고자 했다. 데이터 종류 → 학습률·풀이 형식 → 유지용 혼합 → 학습량 확대 → 생성·시각 읽기·개념 적용 진단 순서로 진행했다.

- 공통 파서로 평가한 전체 MMMU 900문항에서는 B0를 초과한 미세조정 조건이 없었다. 최고 조건은 L1 490/900, B0는 491/900이다.
- 일부 자체 데이터셋 점검은 개선됐지만 다른 작업의 손실이 함께 나타났다.
- 혼합 채점에서도 기록상 모든 학습 조건이 B0보다 낮았다. 그러나 후속 감사에서 명시적 정답 탈락과 불명확한 답의 과잉 인정이 확인돼, 점수 격차를 그대로 능력 저하량으로 해석할 수 없다.
- 진단72에서는 반복 감지 후 최종 답을 출력하는 G2가 후속 검증 후보로 확인됐다.

이 문서는 완료된 결과의 요약이다. 새 학습·추론 또는 수정 채점 정책을 적용한 결과가 아니다.

## 3. 공통 학습·통제 조건

주요 조건은 동일 원본에서 독립적으로 시작했다. 이전 어댑터를 순차적으로 이어 학습하지 않았다. 교사 모델·KD·모델 생성 정답/풀이는 사용하지 않았다.

| 항목 | 주요 학습 설정 |
|---|---|
| 방식 | BF16 LoRA, 정답 데이터 기반 SFT |
| LoRA | rank16, alpha32, dropout0.05 |
| 학습 범위 | 언어 attention·MLP 252모듈, 33,030,144파라미터 |
| 동결 | vision encoder·merger |
| microbatch / accumulation | 1 / 4 |
| optimizer | AdamW, weight decay0.01, clip1.0 |
| warmup | 13업데이트 후 일정 학습률 (P03은2) |
| 최대 학습 길이 | 4,096토큰 |
| 학습 이미지 픽셀 범위 | 200,704~1,003,520 |
| loss / 기타 | assistant 타깃만, gradient checkpointing, packing 없음 |

전체900 평가에서는 문항·정답·이미지·프롬프트·샘플링·출력 상한·반복 감지·공통 파서를 고정했다. 코드에는 manifest/이미지/파서/guard 해시 및 B0 문항별 입력 토큰 수 대조가 있다. 동적 LoRA 커널과 호스트·드라이버 차이는 남아 있으며 비트 단위 동일성을 보장하지 않는다.

문항마다 supervised token 평균 손실을 계산한 뒤 문항을 동일 비중으로 누적한다. 풀이 토큰 비중을 gradient 기여 비율과 동일시하지 않는다.

### 대응 비교의 해석

- E4↔E1, 저학습률 조건↔E2/E5는 데이터·타깃·순서를 유지하고 학습률을 변경했다.

- E6-B↔E6-A는 총 문항·업데이트·학습률을 유지하고 과학 도식 절반을 ChartQA로 교체했다.
- 공간 혼합↔집중은 총 노출이 같지만 CAD 노출은 줄었다. 기존 E7은 학습량이 달라 직접 대응 대조군이 아니다.
- L1↔L2는 노출 수를 맞춘 반복 대 고유 확대 비교지만 분포·토큰 수가 다르다. L2↔L3는 데이터 종류·풀이 비율도 함께 달라졌다.

## 5. 데이터 가공과 과정

원본 이미지·질문·정답을 연결하고 이미지·표·CAD 프로젝트 등 원본 그룹 단위로 학습·점검을 분리했다. 파일·RGB 해시, 질문 정규화, 근접 이미지 후보 등을 검사하고 processor로 이미지·mask·타깃 복원·잘림을 확인했다. 저장 후 별도 프로세스에서 어댑터 재로드·생성을 검증했다. 모든 의미론적 중복을 배제했다는 의미는 아니다.

- E3는 수치 정답과 선택지의 유일한 대응을 검증하고 관계·프로그램을 입력에 넣지 않았다.
- E5는 공식 풀이 500개의 결론과 정답을 대조했고, 파싱 가능한 산술식 268개에서 모순이 없었다. 전체 풀이의 의미론적 증명은 아니다.
- E6-A는 계산26·수치 읽기211·비계산 관계763개다. 공학 계산 전용 데이터로 표현하지 않는다. AI2D의 필요한 ABC 표지가 없는 변형은 제외했다.
- E7은 원본에 QA가 없어 최종 CAD mesh로 상면도 대응 문제를 제작했다. 대칭·유사 실루엣 등을 제외하고 프로젝트 단위로 분리했다. 단면도는 포함하지 않았다.
- L1의 기존 TabMWP 학습1건이 공식 test와 정규화 표 내용을 공유함을 확인했다(질문·RGB는 다름). L1은 기존 동일성을 유지하며 한계를 공개했고 L2/L3는 해당 그룹을 제외했다.
- L1과 과거250업데이트는 비슷한 설정에서도 업데이트2 이후 수치 경로가 달랐다. 차이를 epoch 증가 하나로 단정하지 않는다.

각 수치는 데이터셋별 고정100문항의 자체 점검이며 데이터셋 공식 벤치마크 점수가 아니다.

## 7. 진단72: 생성·이미지 입력 변경

공통 파서 기준60% 이하인18과목에서 각4개를 선정한 오류 강화 표본이다. 전체 MMMU의 대표 표본이 아니다. 새12문항 파일럿 이후 고정72문항을 평가했다.

| 조건 | 변경 | 공통 B0 / L1 | 혼합 B0 / L1 |
|---|---|---:|---:|
| G0 | 기존 생성 대조군 | 23 / 27 | 32 / 32 |
| G1 | 8,064에서 길이 종료되고 답이 없으면 최대128토큰으로 최종 답 출력 | 25 / 36 | 34 / 37 |
| G2 | 반복 감지 시 남은 예산 내 최대128토큰으로 최종 답 출력 | 29 / 34 | 38 / 35 |
| P1 | 원본을 유지하며 규칙 기반 부분 확대 이미지 추가 | 26 / 30 | 34 / 35 |

각 분모는72다. G1/G2는 실제 최종화가 있으면 해당 구간을 채점한 결과다. 원래 중단 정책과 구분하며 두 방식을 결합하지 않았다. 이전 응답·이미지 재입력 비용이 추가된다.

B0 G2는 G0와 첫 단계 응답이 모두 같고6개를 정답으로 회수했다. L1 G1/G2는 첫 단계부터 G0와 달라진 사례가 많아 전체 상승을 최종화만의 효과로 단정하지 않는다. P1은 입력 토큰이 약1.69배로 증가했고 기존 정답 손실도 동반했다.

## 9. 혼합 채점 후속 감사
